User Validation Web Application

Web Programming Lab Assignment. The user submits a login name and password to the server, which checks them against records in a database. A success page is shown on a match, otherwise a failure message.

Python FlaskSQLiteHTML / CSS

Try the demo

GitHub Pages hosts only static files, so this demo is simulated in JavaScript. Try admin / admin123.

How it works

  • The user submits the login form (POST)
  • Flask looks up the user in SQLite
  • The password hash is compared
  • Match: success page. No match: failure message

Passwords are stored hashed and queries are parameterised to prevent SQL injection.

Request flow

Browser --POST /login--> Flask --SELECT ... WHERE username=?--> SQLite
Browser <-- success page / failure message -- Flask
